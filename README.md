# Конвертер разметки → Тангл

Загрузите JSON-файл разметки из **Модуля семантического анализа** — получите
файл проверки для **Тангл** (nanoCAD), готовый к импорту.

## Как пользоваться

1. Нажмите **«Попробовать на примере»**, чтобы прогнать встроенный пример
   («Площадь буфетной в ДОО должна быть больше 10 м²»), либо загрузите свой
   JSON-файл разметки.
2. Нажмите **«Конвертировать»**.
3. Скачайте полученный `tangle.json` и импортируйте его в Тангл.

## Что поддерживается

- **Количественные проверки**: толщина (`XPG_0013`), площадь (`XPG_0005`),
  длина и др. С операторами `equal`, `greater`, `less`, `greaterOrEqual`,
  `lessOrEqual`.
- **Качественные проверки**: материал (`XPM_0002`) и др. — текстовые
  значения из классификатора.
- **AGG-фильтры по типу** (`XNKC0001`/`XNKC0003`) и **по имени** (`ИМЯ`).
- **Единицы измерения**: м, м², м³, мм, см, км — автоматический пересчёт в
  стандартные (мм, мм², мм³).

## Ограничения

- Одна ветка проверки с одним параметром (без AND/OR-комбинаций).
- Хэши (`StrictHashes`/`QueryHashes`) рассчитываются по упрощённому
  алгоритму (SHA-256 от нормализованного JSON). Тангл может пересчитать
  при импорте.
- `CodeExp` фиксированный `(1,1,1)\n.(1,1,1)` для всех кейсов.
